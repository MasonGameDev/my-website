About Me

Hello, My name is Mason. I have made this website several times before on CodeHS. I first started learning code in junior high school, ninth grade to be specific, in the school year of 2025-2026, which was last year.

Though the class only lasted for a semester, I decided to keep coding and improve my skills with the assistance of AI like ChatGPT.

During the semester long class, my teacher who was supposed to teach us coding, was on maternity leave. She set up a course on codehs for us to do at our own pace. The course covered the basics of HTML and CSS but it didn't go into JavaScript. The only JavaScript we learned was this Karel the Dog type of JavaScript. Honestly, I found it not having any relation to JavaScript at all except for the syntax.

At the end of the short and basic HTML and CSS unit, We had to make our own website using the things we learned. I found this to be a very fun project, and that is how the first version of my website was created.

After the class ended, I continued to work on my website and added more features and content with the help of ChatGPT of course. The teacher did eventually return, but we were already too far along to go back, so she told us to have all of the python graphics using the turtle module done by the time we came back from christmas break. Afterwords, we started to do more advanced python graphics on a new coding site called CMU Academy, which was honestly a lot more fun than codehs. The only downside to this new site was the lack of a sandbox whereas codehs provided one where I can pick a coding language and code whatever my heart desired.

Anyway, I kept using ChatGPT to help me improve my coding skills and I eventually became a master of HTML, CSS, and JavaScript. I also dipped my feet into other programming languages such as: Python, C++, and Java. The only language I do not like is Java.

Java is a very confusing language in my opinion. It involves a lot of syntax and concepts that are difficult to grasp at first. I haven't touched java since first trying it out. People sometimes get Java confused with JavaScript, but they are completely different languages. JavaScript is a client-side scripting language, while Java is a general-purpose programming language. Minecraft is a prime example of a game built with Java as the edition on laptop is called Minecraft Java Edition.

Version two of this website took a few months to complete. I was considering trying out a likes system. The system would allow users to like my website and if they disliked it, they would be able to provide feedback that would be sent to me through an email, but I shortly figured out that that would cost me money I don't have.

Another implementation I was considering was adding a feature where it would send me a notification with how many likes my website has received that day. For example, if I received 10 likes today, at 11:59 PM (23:59 military time) I would receive a notification saying, "You have received 10 likes today!" I also shortly figured out that that would cost me money I don't have, and be such a headache to code.

This is just a brief overview of my journey in coding as I plan on taking three different programming classes in my tenth grade year. This version of my website represents my growth and learning in the field of web development as I am using a more complex coding software called Visual Studio (VS) Code. I hope you enjoy my website.
